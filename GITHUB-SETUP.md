# GitHub Setup for Beginners

If you do not already have a GitHub account, start here.

GitHub is where your church notes will be stored. Think of it as the online filing cabinet for your notes. You do not need to learn programming, Git, Python, YAML, or the command line to use this system.

## What you need

- [ ] An email address you can access
- [ ] A web browser
- [ ] A free GitHub account
- [ ] A ChatGPT account
- [ ] About 10 minutes for the initial setup
- [ ] A photo of a church note to test when setup is complete

## Step 1 — Create a GitHub account

1. Go to GitHub and choose **Sign up**.
2. Enter your email address.
3. Create a password.
4. Choose a GitHub username.
5. Complete any verification GitHub requests.
6. Check your email and verify your email address if GitHub asks you to do so.
7. Sign in to GitHub.

You can use GitHub's free account for this project.

## Step 2 — Return to the Church Notes Extractor template

After you are signed in to GitHub, return to the Church Notes Extractor template repository.

On the repository page:

1. Click **Use this template**.
2. Choose **Create a new repository**.
3. Enter a repository name such as `my-church-notes`.
4. Choose **Private** if you do not want your church notes visible to the public.
5. Click **Create repository**.

GitHub will create your own copy of the Church Notes Extractor system.

## Step 3 — Continue the guided setup

Once your new repository is created, open `SETUP.md` in that repository and continue with the instructions beginning at **Step 2 — Allow the automation to update files**.

The rest of the setup will guide you through:

1. Allowing GitHub Actions to update your files.
2. Answering a few setup questions such as your name, church, and Bible translation.
3. Generating your personalized ChatGPT instructions automatically.
4. Connecting your repository to ChatGPT.
5. Uploading your first note.

## One-time ChatGPT ↔ GitHub connection

GitHub account creation and repository setup can be automated or guided, but the security authorization between your ChatGPT account and GitHub must be approved by you.

When you reach the ChatGPT connection step:

1. In ChatGPT, open **Settings → Apps**.
2. Find **GitHub** and choose **Connect**.
3. GitHub will open and ask you to authorize the ChatGPT app.
4. When GitHub asks which repositories ChatGPT may access, choose **Only select repositories** if that option is available.
5. Select only the church-notes repository you just created.
6. Approve the connection.
7. Return to ChatGPT.

This keeps access limited to the notes repository instead of granting access to every repository in your GitHub account.

If the repository does not appear in ChatGPT immediately, wait a few minutes and check again. Newly created or private repositories can take a short time to become available after authorization.

If ChatGPT later asks you to approve an action before saving a note, review the action and approve it only when you want that change made.
